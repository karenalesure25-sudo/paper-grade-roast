# Resume Roast

Build a landing page for “Callback” — a resume roast tool with a “graded paper” aesthetic.

Colors: paper white (#FAF9F6) background, navy ink (#1B2A4A) for headlines/text, red pen (#D6001C) for accents/CTAs, highlighter yellow (#FFE066) for highlights.

Fonts: typewriter-style serif (e.g. “Special Elite” or “Courier Prime”) for headlines and grade stamps, clean sans-serif (e.g. “Inter”) for body text.

Sections:

	1.	Hero — headline “Your resume just got graded.”, subhead “Upload it. Get roasted. Get better. Free.”, CTA button styled like a red rubber stamp reading “Grade My Resume”

	2.	How it works — 3 steps shown as handwritten red-pen margin notes: Upload, Get Roasted + Graded, Unlock the Fix

	3.	Example roast cards — 2-3 sample “graded paper” cards with a letter grade stamp and a witty one-line critique, laid out like scattered papers

	4.	Upsell section — headline “The roast was free. The fix isn’t.”, subhead about real rewrites + ATS scoring, pricing card with “Start My Rewrite” CTA

	5.	Footer — simple, minimal

Add a subtle paper-texture background and a stamp animation when a grade appears. Fully responsive.
